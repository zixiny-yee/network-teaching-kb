# 🎓 中学计算机网络知识库

## 这是什么？

一个装在你自己电脑里的"智能备课助手"，适用于中职与高职院校的计算机网络教师。

把你的教案、知识点整理成文档放入 **docs** 文件夹，双击 `run.bat` 启动，然后在网页里像聊天一样问它问题，它就会根据你的文档资料来回答。

- **不需要联网**，所有东西都在你电脑里，安全又方便
- **支持的文件类型**：txt、docx、pdf

---

## 第一次使用前（只需做一次）

### 1. 安装 Ollama

双击 `OllamaSetup.exe`（或去 https://ollama.com 下载），一路点"下一步"完成安装。

### 2. 下载模型

打开"命令提示符"（开始菜单搜 cmd），输入以下命令并回车：

ollama pull qwen2:0.5b


等待出现 `success` 后，关掉窗口。

### 3. 放置 teaching-kb 文件夹

将整个 `teaching-kb` 文件夹放到 `D:\TECH\` 目录下（没有就新建）。

---

## 怎么用？

### 第一步：启动程序

找到 `D:\TECH\teaching-kb` 文件夹里的 **`run.bat`** 文件，双击它。

会弹出一个黑色窗口，稍等十几秒（它在加载资料），出现 `http://localhost:8501` 后，用浏览器打开这个网址就行了。

> ⚠️ 注意：黑色窗口不要关，关了程序就停了！

> 如果双击没反应，也可以：
> 1. 打开电脑的"命令提示符"（在开始菜单搜 cmd）
> 2. 依次输入 `D:` 回车，`cd D:\TECH\teaching-kb` 回车
> 3. 输入 `python -m streamlit run app_minimal.py` 回车
> 4. 把出现的网址复制到浏览器打开

### 第二步：提问

浏览器打开后，页面底部有个输入框，像发微信一样打字问就行。

比如：
- "什么是TCP和UDP的区别？"
- "怎么给学生讲IP地址？"
- "常见的网络拓扑结构有哪些？"

回答出来后，点下面的"📄 查看参考来源"可以看到它参考了哪份资料。

### 第三步：关闭

用完直接关掉浏览器和黑色窗口就行，下次用再双击 `run.bat`。

---

## 怎么让它变得更好用？

**秘诀就是：往里面加你自己的资料。**

打开 `D:\TECH\teaching-kb\docs` 文件夹，里面是知识库的"大脑"。你可以：

1. **放入文档**：支持 txt、docx、pdf 三种格式
2. **用自己的话写内容**：就像写备课笔记一样，一个文件讲一个知识点
3. **保存后重启程序**：关掉黑色窗口再双击 `run.bat`，新知识就会生效

放进去什么，它就会什么。放的越多，回答越准。

---

## 常见问题

**Q：启动有点慢，卡住了？**
A：正常，等10-15秒就好。它在加载资料，就像老师上课前要翻一下教案。

**Q：回答不太对？**
A：检查一下 `docs` 文件夹里有没有相关的资料。资料越详细，回答越准确。

**Q：必须联网吗？**
A：完全不用。所有东西都在你电脑上，没网也能用。

**Q：我的资料安全吗？**
A：绝对安全。资料不会上传到任何地方，全在你自己的电脑里。
